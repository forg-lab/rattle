rattle: live code music in the browser with Python

rattle is a free live-coding environment for music and generative visuals. You write ordinary Python, press Run and hear it, then edit the code while it plays: each live loop swaps in at its next boundary without dropping the beat. It follows Sonic Pi's model of live loops, synths, samples and effects, and runs entirely in the browser with MicroPython and Web Audio. Nothing to install and no account.

Reference: every function, with examples you can play and edit. Source code on GitHub.
